 V1 — 일단 작동하는 것부터(최소기능 프롬프트)
V1 프롬프트 — 최소기능 백테스팅
업비트 공개 API로 비트코인 4시간봉 데이터를 가져와서
RSI 14 기준으로 백테스트하는 HTML 한 파일을 만들어줘.
조건:
- RSI < 30이면 매수, > 70이면 매도
- 시작 자금 100만 원, 수수료 0.05%
- 결과는 총 수익률, 승률, 거래 수만 표시
- HTML 한 파일이면 됨(서버 없이 브라우저에서 바로 열기)
- Chart.js로 가격 차트와 매수·매도 지점 표시

V2 — 지표 8개 + 그리드 서치(확장 프롬프트)
V1 코드를 베이스로 다음을 추가해줘:
1. 지표 8개 지원(체크박스로 다중 선택)
 RSI, CCI, MFI, Stochastic, Aroon, MACD, Bollinger, Heikin-Ashi
2. 여러 지표 조합 시 결합 로직 선택
 AND(모든 지표 충족) / OR(하나라도 충족) / 과반 충족
3. 종목 6개(BTC, ETH, XRP, SOL, DOGE, ADA),
 봉시간 3종(1H, 4H, 1D), 기간 4종(200/500/1000/2000봉) 선택 가능
4. 그리드 서치 기능 추가
 - 임계값 범위(예: RSI 매수 20~35, 매도 65~80)를 자동 탐색
 - 결과를 히트맵으로 시각화(빨강=손실, 초록=수익)
 - In-Sample 70% / Out-of-Sample 30%로 데이터 분리
 - OOS 수익률 / 샤프 / 종합점수 등 정렬 옵션
5. 프리셋 3종(이미 검증된 조합) 카드로 표시
 - 한 번 클릭으로 모든 설정 자동 적용
6. 다크 테마(배경 #0d1117, GitHub 스타일)
7. 네트워크 진단 패널(Failed to fetch 디버깅용)

 V3 — 검증된 전략 + 손절·익절(실전화 프롬프트)
V2를 다음과 같이 실전 매매 가능 수준으로 업그레이드해줘:
1. 추세 추종 지표 4개 추가
 - SuperTrend(ATR 기반 추세 자동 추종)
 - Ichimoku Cloud(Tenkan/Kijun + 구름)
 - EMA200(장기 추세 필터)
 - ADX(추세 강도 필터)
2. 손절·익절 시스템 4가지 모드
 - 신호 청산만(기본)
 - 고정 % 손절/익절(예: -3%/+6%)
 - ATR 기반 손절 + RR 비율 익절(변동성 적응형)
 - 트레일링 스톱(고점 대비 -3%)
3. 검증된 전략 프리셋 8종을 카드 UI로 추가
 - SuperTrend 단독(BTC 4H, ATR 손절)
 - EMA200 + RSI 풀백(BTC 4H)
 - MACD + RSI(XRP 4H, % 손절)
 - Ichimoku Cloud(BTC 1D, 트레일링)
 - BB + RSI 평균회귀(XRP 1H, 횡보장 전용)
 - SuperTrend + ADX 필터(BTC 4H)
 - EMA200 + MACD + Stoch(Elder의 트리플 스크린)
 - Heikin-Ashi + SuperTrend(강한 추세)
 각 카드는 1클릭으로 모든 파라미터 자동 적용
4. 메트릭 카드에 샤프 지수 추가(5개 → 6개)
5. 거래 내역에 청산 이유 표시(SL/TP/TRAIL/SIG)
