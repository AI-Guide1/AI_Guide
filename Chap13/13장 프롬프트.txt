 예제 1 부서별·제품별 매출 집계(5분 안에 끝내기)

첨부한 매출 원본 데이터를 다음과 같이 정리해서 새 엑셀 파일로 만들어줘.
1. [요약 시트] 부서별·제품군별 매출액 합계 피벗 표
 - 행: 부서, 열: 제품군, 값: 매출액 합계
 - 합계 행/열 추가, 천단위 콤마, 원 단위
2. [부서별 시트] 부서별 영업담당 실적 순위
 - 부서 안에서 매출액 내림차순 정렬
 - 각 담당의 매출 비중(%) 컬럼 추가
3. [TOP 10 시트] 매출액 기준 상위 10개 거래
 - 일자, 담당자, 제품명, 매출액 표시
모든 시트의 헤더는 진한 파란색 배경, 흰 글씨로 강조해줘.
파일명은 매출집계_2026_03.xlsx로 저장해줘.


 예제 2 지저분한 데이터 정제하기
프롬프트
첨부한 거래처 데이터를 정제해서 깨끗한 엑셀로 만들어줘.
[정제 규칙]
1. 거래처명 통일
 - “(주)”, “(유)”, “(재)” 등 법인 표시 제거
 - 공백 모두 제거(예: “한빛 테크” → “한빛테크”)
2. 담당자명 통일 — 이름 사이 공백 제거, 앞뒤 공백 제거
3. 등록일 통일 — 모두 YYYY-MM-DD 형식으로 변환
4. 등급 통일 — 대문자 A/B/C로 통일, 빈 값은 “미지정”으로
5. 매출액 통일 — 숫자만 남기고 ₩, 콤마 제거 후 숫자형으로 저장
[출력]
- 시트1: 정제된 데이터
- 시트2: 정제 전후 비교(어떤 행이 어떻게 바뀌었는지)
- 시트3: 중복 의심 거래처 목록(사람이 최종 확인하도록)

 예제 3 이상치와 트렌드 자동 탐지
첨부한 12개월 치 부서별 매출 데이터를 분석해서 다음을 알려줘.
1. 이상치 탐지
 - 각 부서별로 12개월 평균 대비 ±20% 이상 벗어난 달 찾아내기
 - 이상치가 발견된 행은 셀 배경을 노란색으로 표시
2. 트렌드 분석
 - 각 부서의 12개월 추세(상승/하락/정체) 자동 판정
 - 최근 3개월 평균 vs 이전 9개월 평균 비교
3. 한 줄 요약
 - 각 부서에 대해 “이 부서는 ~한 상황입니다”를 한 문장으로 작성
결과는 [원본 데이터 + 이상치 표시], [요약 분석] 두 시트로 나눠서 저장.

 예제 4 두 개 이상의 파일을 합치고 비교하기
프롬프트
두 개의 엑셀 파일을 합쳐서 전년 동월 대비 비교 보고서를 만들어줘.
[매칭 기준]
- 거래처명 기준으로 매칭
- 거래처명에 차이가 있을 수 있으니, “(주)”, “(유)”, “(재)” 등
 법인 표시와 공백은 제거하고 비교
[출력 시트 구성]
1. 비교 요약: 거래처별 [작년 매출 / 올해 매출 / 증감액 / 증감률]
 - 증감률 +20% 이상은 초록색, -20% 이하는 빨간색 셀 배경
 - 증감률 기준 내림차순 정렬
2. 신규 거래처: 올해만 있는 거래처 목록
3. 이탈 거래처: 작년에는 있었지만 올해 매출 0인 거래처 목록
4. 한눈에 보기: 상위 5개 성장 / 상위 5개 감소 거래처를 한 페이지에

13-2. 재무모델, AI와 함께 만들고 검증하기
프롬프트
손익 시뮬레이션 엑셀 모델을 만들어줘.
[기본 가정]
- 판매단가: 50,000원
- 변동비(개당 원가): 32,000원
- 월 고정비: 8,000,000원
- 현재 월 판매량: 1,500개
[모델 구성]
시트 1: [가정 입력] - 위 4개 값을 사용자가 노란색 셀에서 직접 바꿀 수 있게
시트 2: [기본 손익] - 가정 시트의 값을 참조해 다음 항목 계산
 - 매출액 = 단가 × 수량
 - 변동비 합계 = 개당 변동비 × 수량
 - 공헌이익 = 매출 - 변동비
 - 영업이익 = 공헌이익 - 고정비
 - 영업이익률 = 영업이익 / 매출
시트 3: [수량 × 할인율 시뮬레이션]
 - 행: 단가 할인율 (0%, 5%, 10%, 15%, 20%)
 - 열: 수량 변화 (1,500 / 2,000 / 2,500 / 3,000 / 3,500)
 - 값: 영업이익
 - 영업이익이 현재보다 높으면 초록색, 낮으면 빨간색 배경
시트 4: [의사결정 가이드]
 - “거래처 제안 (단가 -10%, 수량 3,000개)”의 영업이익 계산 결과
 - 현재 대비 증감액 / 증감률
 - “수락 권장” / “거절 권장” 판단과 그 근거 한 줄
모든 셀의 수식은 가정 시트를 참조해서, 가정값만 바꾸면
모든 시트가 자동 업데이트되게.
파일명: 손익시뮬레이션_기본모델.xlsx

 예제 2 NPV·IRR로 “이 프로젝트 할까?” 결정하기
클로드 프롬프트(투자분석_장비도입_NPV.xlsx)
신규 장비 투자 NPV/IRR 분석 모델을 만들어줘.
[기본 가정]
- 초기 투자: 300,000,000원 (1년차 초)
- 1년차 순현금흐름: 60,000,000원
- 2년차: 90,000,000원
- 3년차: 120,000,000원
- 4년차: 110,000,000원
- 5년차: 95,000,000원 (말기 잔존가치 포함)
- 할인율 (요구수익률): 8%
[출력 시트 구성]
시트 1: [가정 입력] - 위 값들을 노란색 셀에서 직접 수정 가능
시트 2: [NPV/IRR 계산]
 - 연차별 현금흐름, 할인계수 (1/(1+r)^n), 현재가치 컬럼
 - NPV 합계, IRR 자동 계산 (NPV, IRR 함수 사용)
 - 회수기간 (Payback Period) 계산도 포함
 - 결론 셀: NPV>0 이고 IRR>할인율이면 “투자 권장”,
 아니면 “재검토 필요”
시트 3: [할인율 민감도 분석]
 - 행: 할인율 (5%, 6%, 7%, 8%, 9%, 10%, 12%, 15%)
 - 열: NPV 값
 - NPV가 0보다 크면 초록, 작으면 빨강 셀 배경
 - “이 프로젝트는 할인율 X%까지는 투자 가치가 있습니다” 자동 문구
시트 4: [시나리오 분석]
 - 비관/중립/낙관 3가지 시나리오(현금흐름을 -20%, 0%, +20%로)
 - 각 시나리오의 NPV, IRR
파일명: 투자분석_장비도입_NPV.xlsx
