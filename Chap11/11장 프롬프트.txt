11-2. 1단계 학습 콘텐츠 풀 만들기
콘텐츠 풀을 만드는 프롬프트
한국 30~40대 직장인을 위한 영어 학습 콘텐츠를 만들어줘.
다음 세 가지 카테고리에 각각 8개씩, 총 24개를 작성:
1. Listening(듣기 스크립트)
 - 일상·직장·여행 상황의 자연스러운 영어 대사
 - 20~40초 분량, 한국어 해석 같이
 - 난이도(초/중/고)와 시간 표기
2. Sentence(오늘의 문장)
 - 실제로 자주 쓰이는 패턴 한 문장
 - 한국어 해석 + 문법 포인트 한 줄 + 짧은 추가 예문
3. Conversation(회화)
 - 4줄짜리 짧은 대화(A·B 두 명)
 - 카페·회의·식당·택시·병원 등 실생활 장면
 - 영어와 한국어 해석 같이
결과는 JavaScript 객체 형태로,
나중에 코드에 그대로 붙여넣을 수 있게 해줘.

11-3. 2단계 대시보드 UI 설계
다음 콘텐츠 풀을 사용해서 “Daily English” 대시보드를
HTML 파일 한 개로 만들어줘.
요구사항:
1. 화면 구성
 - 상단: 오늘 날짜 / “오늘의 학습” “복습 보관함” 탭
 - 통계 카드 3개(학습 일수, 완료한 항목, 보관 중)
 - 학습 카드 3장(Listening / Sentence / Conversation)
 - 하단: [새 콘텐츠 불러오기] [모든 데이터 초기화] 버튼
2. 매일 다른 콘텐츠를 자동 표시
 - 오늘 날짜를 기준으로 콘텐츠 풀에서 항목 선택
 - 같은 날 새로고침해도 같은 콘텐츠 유지
3. 각 카드에 [🎧 듣기] 버튼
 - 브라우저 Web Speech API로 영어 문장 읽어주기
 - 영어 발음, 약간 느린 속도(0.95)
4. [★ 보관] / [✓ 완료] 버튼
 - 보관 목록과 완료 기록은 localStorage에 저장
 - “복습 보관함” 탭에서 보관 항목 다시 보기·재생·삭제 가능
5. 디자인
 - 따뜻한 베이지 배경(#FAF9F5)
 - 카드 흰색, 부드러운 라운드, 미니멀
 - 다크 모드 자동 대응
[콘텐츠 풀]
... (앞 단계에서 받은 24개 데이터 붙여넣기)

11-5. 확장 가족·동료와 함께 쓰는 법

변경 사항:
1. Listening: 동물·학교·놀이 주제, 한 문장 5~10초
